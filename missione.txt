──────────────────────────────────────────────────────────────────────────────
  SITUAZIONE
──────────────────────────────────────────────────────────────────────────────

Nella notte tra il 14 e il 15 novembre 2024 un intruso non identificato ha
violato i sistemi informatici del Portale Sicuro della Polizia di Stato.
L'accesso è avvenuto da un IP esterno tramite SQL Injection sull'interfaccia
di login. Sono stati compromessi dati riservati e corrotti record interni.

Danni accertati:
  - Alterazione delle schede anagrafiche di alcuni agenti
  - Eliminazione di un record dal registro del personale
  - Esfiltrazione di dati sensibili verso un server esterno sconosciuto
  - Tracce di un'organizzazione criminale denominata "NEXUS"

Il tuo compito: ricostruire l'attacco, risalire all'identità dei responsabili
e neutralizzarli definitivamente.

──────────────────────────────────────────────────────────────────────────────
  FASE 1 — INDAGINE SUL PORTALE POLIZIA
──────────────────────────────────────────────────────────────────────────────

  URL: http://localhost/HackTheHacker/polizia/

  Le credenziali di accesso ti sono state consegnate nel briefing iniziale.
  Se le hai perse, cerca bene — i programmatori lasciano sempre qualcosa.

  Pagine da esaminare:

  [ ] DASHBOARD       — panoramica generale del sistema
  [ ] ANAGRAFICA      — registro agenti: quali schede sono state manomesse?
  [ ] MANDATI         — operazioni in corso: qualcosa non torna?
  [ ] MESSAGGI        — comunicazioni interne: ci sono avvisi tecnici utili?
  [ ] REPORT          — incidenti registrati: uno è classificato CRITICO.
                        Il codice sorgente di questa pagina merita attenzione.

  Prima di procedere devi avere in mano:
    → L'IP da cui è partito l'attacco

──────────────────────────────────────────────────────────────────────────────
  FASE 2 — ANALISI FORENSE — TERMINALE DB
──────────────────────────────────────────────────────────────────────────────

  URL: http://localhost/HackTheHacker/polizia/terminale.php

  Hai accesso a un terminale MySQL in sola lettura sul database della polizia.
  Sono consentite solo query SELECT, SHOW e DESCRIBE.

  [ ] Scopri quali tabelle esistono nel database.
  [ ] La tabella server_log registra ogni operazione sul sistema.
      Analizza la sua struttura, poi interrogala con attenzione.
  [ ] Filtra i log per trovare l'azione che rivela la destinazione finale
      dei dati esfiltrati.

  Il risultato di quella query ti consegnerà l'URL del server nemico.
  Annotalo: è la porta di ingresso alla Fase 3.

──────────────────────────────────────────────────────────────────────────────
  FASE 3 — INFILTRAZIONE NEL SERVER NEXUS
──────────────────────────────────────────────────────────────────────────────

  URL: [da scoprire nella Fase 2]

  Sei nel territorio del nemico. Il gruppo NEXUS gestisce qui il proprio
  sistema di command-and-control. Hai bisogno delle loro credenziali —
  guarda bene il codice sorgente della pagina di accesso.

  [ ] DASHBOARD       — panoramica operazioni e stato del sistema
  [ ] MEMBRI          — registro alias dei componenti del gruppo
  [ ] OPERAZIONI      — log delle attività criminali (ultime 50, espandibile)
  [ ] FILE RUBATI     — archivio dati esfiltrati (ultime 50, espandibile)
                        In fondo alla pagina trovi una partizione riservata
                        con tre file anomali. Ognuno va letto in modo diverso:
                          · Uno è solo questione di come si chiama il file.
                          · Uno usa una codifica molto diffusa su internet.
                          · Uno è cifrato con un metodo antico e invertibile.
                        Il terzo file contiene informazioni CRITICHE per il caso.
  [ ] ADMIN CONSOLE   — accessibile solo con i privilegi giusti.
                        Qui si chiude il caso. Digita help per iniziare.

──────────────────────────────────────────────────────────────────────────────
  VERIFICA FINALE
──────────────────────────────────────────────────────────────────────────────

  URL: http://localhost/HackTheHacker/solution/soluzione.php

  Al termine dell'operazione inserisci le tre prove chiave raccolte:

    PROVA 1 — L'indirizzo IP dell'attaccante
              (trovato analizzando il server_log nel Terminale DB)

    PROVA 2 — La password temporanea del server NEXUS
              (ottenuta decifrando il terzo file nella partizione riservata)

    PROVA 3 — Il comando finale eseguito nella Admin Console
              (il comando SQL che ha neutralizzato il database di NEXUS)

  Il sistema verificherà le risposte e registrerà il tuo punteggio (0-3)
  nella classifica ufficiale con data e ora.

  Puoi accedervi anche dal pulsante "VERIFICA LA TUA SOLUZIONE" che compare
  automaticamente nella schermata finale dopo il colpo di grazia.
